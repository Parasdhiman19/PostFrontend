# PostFrontend

React 19, TanStack Query v5, and Tailwind CSS v4 frontend for the BlogSpace / Posts platform.

## Features
- **Modern React 19** with clean client architecture
- **TanStack Query v5** for caching, optimistic updates, and background refetching
- **Automatic Pagination** (IntersectionObserver-based infinite scroll)
- **Fluid Momentum Smooth Scrolling** powered by Lenis
- **Markdown Editor & Live Preview** with XSS-safe rendering
- **Threaded Hierarchical Comments** & multi-tier reaction buttons
- **Real-time Cache Inspector** for monitoring Query Cache slots
- **Dark / Light Theme** with refined contrast and frosted glass navigation

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

### 4. Run Linter
```bash
npm run lint
```
